3. API key：MINIMAX_API_KEY 完整迁入 .env，验证 hasApiKey:true

## 关键设计决策
1. **方案A：Vercel Serverless** 已落地
   - 后端从「常驻 Express + 同步长轮询」改为「Serverless Functions + 异步 taskId + 前端轮询」
   - 避开 300s 函数时长限制
2. **JSON 协议**（含 base64 内嵌文件）：dev 和 prod 完全一致
   - 4.5MB body 限制下，base64 文件 ≈ 3.4MB；超出会提示用户压缩
3. **共享模型适配层** `lib/models.cjs`：被 api/*.js 与 server/index.cjs 共同 require
   - 适配器接口：createTask(params, apiKey) → externalTaskId；queryTask(id, apiKey) → { status, videoUrl?, error? }
   - minimax-h3 已实现；wan-3.0 / seedance-2.5 占位（接入只需加 adapter + 环境变量）
4. **任务 ID 编码**：`modelId:externalTaskId`，无需持久化即可路由回 adapter
