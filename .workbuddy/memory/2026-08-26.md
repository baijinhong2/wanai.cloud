## 邮箱验证码注册（Resend + Supabase 存储）
- 背景：注册原为无验证码直插数据库。为防垃圾注册，接入邮箱验证码。
- 发信服务：**Resend 免费版（3000 封/月）**，域名 wanai.cloud 已验证（DKIM `resend._domainkey` ✅、SPF 子域 `send.wanai.cloud` TXT `v=spf1 include:amazonses.com ~all` ✅）
- 关键坑：Resend MX（`send` 子域）与 Cloudflare Email Routing MX（`@` 顶级域）**不冲突**（子域 vs 顶级域），但 Resend 要求 SPF+MX 同时绿才 Verified；MX 优先级 10 若加到顶级域会抢收信，所以只加在 send 子域
- 数据库：新建表 `wanai_verify_codes`（email, code, expires_at, used, created_at）+ 索引
- 后端：`src/app/api/send-code/route.ts`（60s 限流 / 单日 10 次 / 5 分钟过期 / 旧码作废防重放 / Resend API 发信）；`register` 校验验证码（auth.ts 第 3 参 code，通过后标记 used 防重放）
- 前端：`AuthModal.tsx` 注册表单加验证码输入 + 「发送验证码」按钮（60s 倒计时）；`auth.tsx` 的 register 增加 code 参数、新增 sendCode()
- `.env` 新增：`RESEND_API_KEY`、`RESEND_FROM=WanAI.cloud <no-reply@wanai.cloud>`（不提交 git）
- 验证：错误路径（无效邮箱/格式/错误码/缺码）全部正确；成功路径真实发信→入库→注册返回 token→清理测试数据；tsc 0 错误
